# Portfolio Customization Checklist

Use this checklist to customize the portfolio with your information.

## 1. Hero Section (`src/components/Hero.vue`)
- [ ] Change "Hi, I'm Kelvin" to your name
- [ ] Update headline from "Full-Stack Developer & Creative Problem Solver" to your headline
- [ ] Update location (currently "Your Location")
- [ ] Update bio text
- [ ] Add your CV/Resume link if desired

## 2. About Section (`src/components/About.vue`)
- [ ] Update about me paragraphs with your story
- [ ] Customize the skills list (currently has 12 skills)
- [ ] Add/remove skills based on your expertise
- [ ] Update descriptions to match your background

## 3. Experience Section (`src/components/Experience.vue`)
- [ ] Update all job positions with your experience
- [ ] Add your actual companies
- [ ] Update job dates/periods
- [ ] Write descriptions of your accomplishments (currently shows example bullet points)
- [ ] Update technologies for each position

## 4. Projects Section (`src/components/Projects.vue`)
- [ ] Add your actual projects (currently has 4 example projects)
- [ ] Update project names, descriptions, and icons
- [ ] Add GitHub repository links
- [ ] Add live demo links (or remove if not applicable)
- [ ] Update technologies for each project
- [ ] Consider adding project images/thumbnails later

## 5. Footer/Contact Section (`src/components/Footer.vue`)
- [ ] Update email address to your email
- [ ] Add your LinkedIn profile URL
- [ ] Add your GitHub profile URL
- [ ] Update copyright year if needed
- [ ] Customize the contact message

## 6. Navigation (`src/components/Navigation.vue`)
- [ ] Update the logo/name from "Kelvin" to your name

## 7. HTML Meta Tags (`index.html`)
- [ ] Update title to "YourName - Your Headline"
- [ ] Update meta description
- [ ] Update favicon if you have one

## 8. Color Customization (Optional)
Edit `tailwind.config.js` to change the color scheme:
- [ ] Modify `primary` color (currently `#3b82f6` - blue)
- [ ] Modify `dark` background color (currently `#0f172a` - dark slate)
- [ ] Update gradient colors in components if desired

## Quick Start Commands

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
